# Family Medicine Conference Website — Deep Dive 2026

متطلبات تصميم الموقع الالكتروني لمؤتمر طب الأسرة

Deep Dive 2026

 

الهدف: تصميم موقع إلكتروني حديث واحترافي يمثل الهوية الرسمية للمؤتمر، ويتيح للزائر الوصول السريع إلى المعلومات والتسجيل والتقديم العلمي بسهولة.

 

الهوية والتصميم العام

• استخدام هوية بصرية موحدة وألوان حديثة ومناسبة لمؤتمر صحي علمي، مع إبراز اسم المؤتمر وشعاره بوضوح.

• إتاحة اختيار اللغة العربية أو الإنجليزية، مع عرض صحيح لاتجاه النص في كل لغة.

• تصميم متجاوب Responsive Design يظهر بجودة عالية وسهولة استخدام على الجوال والأجهزة اللوحية وأجهزة الكمبيوتر.

• أن يكون الموقع سريعًا وواضحًا وسهل التصفح، مع إبراز الأزرار الرئيسية في جميع الصفحات.

 

الصفحة الرئيسية

• عرض اسم المؤتمر وعنوانه بشكل بارز، مع نبذة مختصرة عنه.

• عرض التاريخ والوقت والموقع وعدد أيام المؤتمر وعدد ساعات التعليم الطبي المستمر CME Hours

• إضافة عداد تنازلي لموعد المؤتمر.

• إضافة أزرار مباشرة وواضحة تشمل: 

o التسجيل الآن

o تقديم الملخصات والبوسترات

o البرنامج العلمي

o ورش العمل

• قسم مختصر لأبرز أرقام المؤتمر، مثل عدد الأيام والساعات والمتحدثين والجلسات وورش العمل، بعد اعتماد الأعداد النهائية.

 

المحتوى التعريفي والعلمي

• نبذة عن المؤتمر، والرؤية والرسالة، والفئات المستهدفة، وأهم أسباب الحضور.

• ملخص للبرنامج العلمي في الصفحة الرئيسية، مع صفحة مستقلة للبرنامج الكامل وإمكانية تحميله بصيغة PDF

• صفحة لورش العمل تشمل: 

o عنوان الورشة

o التاريخ والوقت

o اسم المدرب

o الفئة المستهدفة

o عدد المقاعد

o الرسوم 

o زر التسجيل

• صفحة للمتحدثين تشمل الصورة، والاسم، والتخصص، والمسمى الوظيفي، وجهة العمل، ونبذة مختصرة.

• صفحة لقيادة المؤتمر تشمل رئيس المؤتمر واللجان المنظمة والعلمية.

 

التسجيل والأسعار

• صفحة واضحة لفئات التسجيل والأسعار والفترات المحددة، مثل التسجيل المبكر والتسجيل المنتظم.

• توضيح ما يشمله التسجيل وسياسة الإلغاء والاسترداد عند اعتمادها.

• ربط زر التسجيل مباشرة بنظام التسجيل والدفع المعتمد، مع إظهار حالة نجاح العملية للمستخدم.

• إمكانية إضافة عداد تنازلي لانتهاء التسجيل المبكر عند الحاجة.

 

الملخصات والبوسترات

• قسم مستقل بعنوان:
Call for Abstracts & Poster Submission

• عداد تنازلي لموعد إغلاق التقديم، مع زر مباشر لنموذج التقديم.

• عرض تاريخ إغلاق التقديم، وموعد إشعار القبول، وشروط التقديم، وإرشادات إعداد الملخص والبوستر.

• إتاحة تحميل الإرشادات والملفات المعتمدة، وتحديد وسيلة تواصل للاستفسارات العلمية.

 

الموقع والرعاة والتواصل

• عرض اسم مقر المؤتمر والعنوان والخريطة التفاعلية، مع زر الحصول على الاتجاهات.

• عرض شعارات الرعاة والشركاء وتصنيفهم حسب فئات الرعاية المعتمدة.

• إضافة قسم للتواصل مقسم إلى: 

o دعم التسجيل

o الملخصات والبوسترات

o الرعاية والمعرض

o الاستفسارات العامة

## التشغيل محليًا

```sh
bun install
bun run dev        # http://localhost:8080
```

## النشر على Cloudflare Workers

```sh
bun run preview    # بناء وتشغيل الموقع محليًا بنفس بيئة Cloudflare
bun run deploy     # بناء ورفع الموقع (يتطلب npx wrangler login مرة واحدة)
```

أو من لوحة Cloudflare: **Workers & Pages → Create → Import a repository**
- Build command: `bun run build`
- Deploy command: `npx wrangler deploy`

متغيرات التشغيل (Settings → Variables and Secrets):

| المتغير | الغرض |
| --- | --- |
| `SUPABASE_URL` / `SUPABASE_PUBLISHABLE_KEY` | قاعدة البيانات (نفس قيم `.env`) |
| `SUPABASE_SERVICE_ROLE_KEY` | حفظ التسجيلات من السيرفر |
| `MOYASAR_SECRET_KEY` | الدفع عبر ميسر |

متغيرات `VITE_*` تُقرأ وقت البناء من ملف `.env`.
